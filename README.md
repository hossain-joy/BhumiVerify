## এক নজরে প্রকল্প (Overview)

**ভূমিভেরিফাই (BhumiVerify)** হলো জমি কেনার আগে সাধারণ ক্রেতাদের জন্য একটি আধুনিক প্রি-রেজিস্ট্রেশন যাচাইকরণ প্ল্যাটফর্ম। জমি কেনার পর যাতে কোনো আইনি বা আর্থিক জটিলতায় পড়তে না হয়, সেজন্য বায়না করার আগেই জমির যাবতীয় রেকর্ড ও মাঠপর্যায়ের যাচাই সম্পন্ন করতে এই সিস্টেম সাহায্য করে।

## কেন এই প্ল্যাটফর্ম? (Why BhumiVerify?)

বাংলাদেশে জমি ক্রয়ে ক্রেতারা যেসব প্রধান সমস্যার মুখোমুখি হন:
- **জাল বা ভুয়া দলিল:** পূর্বের মালিকানার ধারাবাহিকতা (Chain of Title) স্পষ্ট না থাকা।
- **নামজারি গোপন রাখা:** জমি বিক্রির আবেদন হলেও খতিয়ানে এখনো পূর্বের মালিকের নাম থাকা।
- **একই জমি একাধিক বিক্রি:** সাব-রেজিস্ট্রি অফিসে সঠিক তল্লাশি না করে বায়না দেওয়া।
- **দালালি ও অসত্য তথ্য:** মাঠপর্যায়ের শারীরিক দখল ও সীমানা নিয়ে বিরোধ।

ভূমিভেরিফাই এসব ঝুঁকি কমাতে ক্রেতাকে একটি নির্ভরযোগ্য ও কাঠামোগত যাচাইকরণ পদ্ধতি প্রদান করে।

## সাব-রেজিস্ট্রি অফিস সংযোগ ও মামলা যাচাই (Sub-Registry Office & Litigation Verification)

ভূমিভেরিফাই প্ল্যাটফর্মে রয়েছে সাব-রেজিস্ট্রি অফিসের সাথে সরাসরি ডিজিটাল সংযোগ (Live Gateway) এবং দেওয়ানি আদালত ডাটাবেজ সমন্বিত যাচাই ব্যবস্থা:

### ১. এলটি নোটিশ (LT Notice - Land Transfer Notice) থেকে স্বয়ংক্রিয় সিদ্ধান্ত
- **৮৯ ধারা নোটিশ প্রবাহ:** সাব-রেজিস্ট্রি অফিসে কোনো দলিল (সাফ-কবলা, হেবা ইত্যাদি) রেজিস্ট্রি হলে রাষ্ট্রীয় অধিগ্রহণ ও প্রজাস্বত্ব আইন (SAT Act) এর **৮৯ ধারা অনুযায়ী** সাব-রেজিস্ট্রার স্বয়ংক্রিয়ভাবে একটি এলটি নোটিশ সহকারী কমিশনার (ভূমি) রাজস্ব সার্কেলে প্রেরণ করেন।
- **রেজিস্ট্রি বনাম নামজারি বিশ্লেষণ:** এই নোটিশের মাধ্যমে সিস্টেম সরাসরি শনাক্ত করে জমিটি সম্প্রতি কেউ রেজিস্ট্রি করেছে কি না এবং রাজস্ব রেকর্ডে নামজারি (e-Mutation) করার আবেদন চলমান রয়েছে কি না। ফলে ক্রেতা বুঝতে পারেন জমিটির মালিকানা বর্তমানে কার অনুকূলে হস্তান্তরিত হচ্ছে।

### ২. ১২ থেকে ২৫ বছরের সাব-রেজিস্ট্রি তল্লাশি (12-25 Year Nil Search)
- সাব-রেজিস্ট্রি অফিসের **১ নম্বর বালাম বহি (Book 1)** এবং **সূচি বহি (Index 1 & 2)** তল্লাশ করে দেখা হয় বিগত ১২ থেকে ২৫ বছরের মধ্যে জমিটি কোনো ব্যাংক বা আর্থিক প্রতিষ্ঠানের কাছে মর্টগেজ (Mortgage) রাখা হয়েছিল কি না কিংবা কোনো গোপন বায়নানামা ও পাওয়ার অব অ্যাটর্নি রয়েছে কি না।

### ৩. "জমিতে মামলা আছে নাকি নাই?" (Litigation Verdict)
- **মামলা নাই (Litigation Free & Clear Title):** আদালত ও সাব-রেজিস্ট্রি রেকর্ডে কোনো বিচারাধীন দেওয়ানি মোকদ্দমা, স্বত্ব ঘোষণা, বাটোয়ারা বিরোধ বা নিষেধাজ্ঞা নেই। ক্রেতা নির্দ্বিধায় বায়না প্রক্রিয়ায় এগোতে পারেন।
- **মামলা আছে (Active Lawsuit & Injunction Warning):** জমিতে সক্রিয় দেওয়ানি মোকদ্দমা (মোকদ্দমা নং, আদালত ও মামলার বিষয়) এবং আদালত কর্তৃক অস্থায়ী নিষেধাজ্ঞা (Ad-interim Injunction) বলবৎ থাকার সুস্পষ্ট লাল সতর্কতা। ক্রেতার জন্য পরিষ্কার রায়: **"ক্রয় ও বায়না সম্পূর্ণ স্থগিত রাখুন!"**

## প্রযুক্তিগত কাঠামো (Tech Stack)

- **Frontend:** React 18, TypeScript, Tailwind CSS
- **Build Tool:** Vite 6
- **Icons:** Lucide React
- **Storage:** Local Storage Adapter (রিবুট প্রতিরোধী)
- **Voice Engine:** Web Speech Synthesis API (বাংলা ও ইংরেজি)
- **Testing:** Node.js Assert Suite (Security + CRUD: 14/14 Passed)

## লোকাল সেটআপ ও রান (Setup Guide)

### ১. ক্লোন ও ইনস্টল
```bash
git clone https://github.com/hossain-joy/BhumiVerify.git
cd BhumiVerify
npm install
```

### ২. লোকাল সার্ভার চালু
```bash
npm run dev
```
ব্রাউজারে ওপেন করুন: `http://localhost:5173/`

### ৩. স্বয়ংক্রিয় টেস্ট রান
```bash
npm test
```
*(নিরাপত্তা, ইনপুট ভ্যালিডেশন, কোটা এবং সম্পূর্ণ CRUD অপারেশনের টেস্ট রান হয়)*

### ৪. প্রডাকশন বিল্ড
```bash
npm run build
```
